# Plantel

## Como ver o site no seu computador
1. Abra esta pasta no VS Code (Arquivo > Abrir pasta).
2. Instale a extensão **Live Server**. Depois clique com o botão direito em `site/index.html` e escolha "Open with Live Server".
   - Outra opção, se tiver Python: no terminal, rode `cd site` e depois `python -m http.server 8000`, e abra http://localhost:8000
3. Abrir o index.html com dois cliques **não** funciona, porque o site precisa carregar o data.json por um servidor.

## Como usar o Claude Code aqui
Instale a extensão "Claude Code" no VS Code e abra esta pasta. O arquivo `CLAUDE.md` já explica o projeto inteiro para ele.
